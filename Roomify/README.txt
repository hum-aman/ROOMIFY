ROOMIFY — Front-end prototype

HOW TO RUN
1. Extract ROOMIFY.zip.
2. Open the ROOMIFY folder.
3. Double-click index.html and open it in Chrome or another modern browser.

INCLUDED IN THIS VERSION
- Create a Room button, followed by Limited Room / Unlimited Room.
- Limited Room capacity choices (2, 4, 6, 10, 20, 30, 50).
- Custom room code with letters, numbers, @, _ and -.
- Generate Random Code and regenerate option.
- A room code is required to join.
- Display name, invite link, local chat preview, file selection preview.
- Room data is saved in this browser using localStorage.

IMPORTANT LIMITATION
This is a front-end prototype. Rooms and messages are stored only in the same browser on the same device. Invite links do not yet connect different devices. Real multi-user chat, online status, cloud photo/file sharing, and voice/video calls require a backend/database, file storage and WebRTC/media services. “Unlimited” means no fixed cap in this prototype; actual hosting and network capacity will still have limits.
